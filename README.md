# Plagiarism Detection Tool

A plagiarism detection tool with a C++ backend and a web-based frontend.

## Project Structure

```
Plagiarism_tool_Final/
├── backend/          # C++ backend server (main.cpp)
├── frontend/         # Web frontend (HTML, CSS, JS)
│   ├── index.html
│   ├── style.css
│   └── script.js
├── documents/        # Sample documents for testing
├── reports/          # Generated plagiarism reports
└── code_Plagiarism.cpp  # Core plagiarism detection logic
```

## Features

- Text plagiarism detection
- Web-based UI for easy interaction
- C++ powered backend for fast processing

## Usage

1. Build the backend: compile `backend/main.cpp`
2. Open `frontend/index.html` in your browser
3. Upload documents to check for plagiarism
